# Fantasy Baseball League Analysis

Overview site: **https://aarongzmn.github.io/fantasy-baseball-league-analysis/**

**Fantasy Baseball League Analysis** is a private, non-commercial MLB fantasy companion dashboard built for personal and single-league analysis.

## Summary
- **Scope:** Personal MLB fantasy league analysis (combining Yahoo Fantasy league settings, standings, weekly matchups, and rosters with public MLB statistical splits and Statcast metrics).
- **Permissions:** Read-Only via Yahoo OAuth 2.0.
- **Distribution:** Private self-hosted web application (no public distribution or commercial use).
