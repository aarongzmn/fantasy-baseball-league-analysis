# Fantasy Baseball League Analysis

Overview site: **https://aarongzmn.github.io/fantasy-baseball-league-analysis/**

**Fantasy Baseball League Analysis** is a private, non-commercial MLB fantasy companion dashboard built strictly for personal / single-league use (1–12 league members).

## Summary
- **Scope:** Personal, single-league MLB analysis (combining Yahoo Fantasy league settings, standings, weekly matchups, and rosters with public MLB statistical splits and Statcast metrics).
- **Permissions:** Read-Only (`fspt-r`) via Yahoo OAuth 2.0. Zero write calls or automated transactions.
- **Distribution:** Private self-hosted web application (application source code is maintained in a private repository; no public distribution or commercial use).
